How the Oordio Assignment Ladder Works

A deep dive into the relationship-first automation that keeps your turnarounds covered

When a guest checks out, you need a cleaner—fast. The old way: text your primary, wait, maybe text a backup, wait again. The Oordio way: the system offers the job in a strict priority order, escalates automatically when someone declines or times out, and notifies you only when human intervention is needed. Here's exactly how it works.

The Four-Step Ladder

Oordio uses a relationship-first assignment ladder. Your trusted cleaners get first dibs; the marketplace is a fallback, not the default.

Step 1: Primary Cleaner

Every property has a primary_cleaner_id. When a job is created (e.g. from a confirmed Airbnb booking), Oordio immediately offers it to this person. They receive a push notification with job details: property, checkout time, checklist. They have a time-limited window to accept or decline.

If they accept → job is assigned, you're done. If they decline or don't respond in time → Oordio moves to step 2. No manual handoff.

Step 2: Backup Cleaner

If you've set a backup_cleaner_id on the property, Oordio offers the job to them next. Same flow: push notification, acceptance window. The window is typically shorter than primary (e.g. 24 hours vs 48 hours when checkout is more than 48h away) because time is tighter.

If they accept → assigned. If they decline or expire → step 3.

Step 3: Marketplace

If marketplace_enabled is true on the property, Oordio creates a marketplace job request. This is a posting that vetted marketplace cleaners can browse and bid on. You get a notification that a posting was created; you can review bids and accept one. If no one bids or you don't accept in time, Oordio moves to step 4.

Step 4: Unassigned

When primary, backup, and marketplace are all exhausted, Oordio marks the job as unassigned and notifies you once. You can then manually assign a cleaner, find someone outside the system, or adjust the booking. The system doesn't spam you—it escalates to you only when it needs human help.

The 48-Hour Hard Deadline

Every offer must expire at least 48 hours (2 days) before checkout. Why? So that if a cleaner declines or times out, you still have time to escalate to backup or marketplace and get someone confirmed before the guest arrives.

When checkout is far away (e.g. 5 days), the primary might get 48 hours to respond. When checkout is in 3 days, the window is capped so it still expires 48h before. When checkout is within 48 hours (urgent), Oordio uses shorter fallback windows: 4 hours for primary, 2 for backup, 60 minutes for marketplace. Same-day turnarounds get even tighter windows (60 min, 30 min, 20 min) but the floor is always 15 minutes—cleaners always get some time to respond.

Reminder Strategy

Cleaners are busy. Oordio sends reminders so they don't miss offers:

  • Offer sent — 1 push notification when the job is first offered
  • 50% elapsed — First reminder
  • 75% elapsed — Second reminder (skipped if window < 2 hours)
  • 90% elapsed — Third reminder (skipped if window < 4 hours)

For very short windows (< 30 min), only one reminder at 50%. Maximum 4 notifications per job per cleaner. No spam.

When an offer expires, Oordio does not send an "offer expired" notification. It silently moves to the next step. The cleaner isn't bombarded; the system just escalates.

Booking Time Changes

If checkout time changes by 30 minutes or more (guest extends, host adjusts):

  1. If a cleaner is already assigned, Oordio asks them to reconfirm with a 60-minute window. If they decline, the flow restarts at backup or marketplace.
  2. If an offer is still pending, Oordio cancels it and restarts the flow with the new time.

No stale assignments. No confusion about when to show up.

Event Logging

Every step is logged: OFFER_SENT, REMINDER_SENT, ACCEPTED, DECLINED, EXPIRED, ESCALATED, REASSIGNED, UNASSIGNED, HOST_NOTIFIED, BOOKING_CHANGED, RECONFIRM_REQUESTED. You can trace the full history of any job.

Why This Matters

The ladder removes the manual back-and-forth. You set primary and backup once; Oordio handles the rest. You get notified only when the system needs you. Cleaners get clear, time-bounded offers with reminders—no ambiguity. The result: fewer missed turnarounds, happier guests, and more time for you to focus on growth.
